# free-model-catalog

Free-tier model access is time-limited and changes often. This repository keeps a
**script that fetches the live model list** from OpenAI-compatible providers and filters
the free subset, so you read a fresh snapshot instead of a hand-maintained list.

- Stdlib only (Python 3.9+), no dependencies.
- Keys are read from environment variables and never written to disk.
- Output: `catalog/latest.json` (model IDs, provider, free reason, context length, fetch time).

## Usage

```bash
python scripts/fetch_free_models.py --out catalog/latest.json
```

Add a provider by editing `providers.json`:

| field | meaning |
| :--- | :--- |
| `models_url` | OpenAI-compatible `GET /models` endpoint |
| `auth_env` | environment variable holding the key, or `null` for public listing |
| `user_agent` | some providers reject the default Python agent |

## Free detection

A model is marked free when either:

1. its id ends with `:free` or contains `-free`, or
2. the provider reports `prompt` and `completion` prices as exactly `0`.

Rule 1 is a naming convention, not a contract. Check the provider's terms before relying on it.

## Scheduling

Free tiers expire, so refresh regularly, for example with cron:

```cron
0 */6 * * *  cd /path/to/free-model-catalog && OPENROUTER_API_KEY=... python3 scripts/fetch_free_models.py
```

Exit code is `1` when any provider fails, so a scheduler can alert on it.

## Current snapshot

See [`catalog/latest.json`](catalog/latest.json). It is regenerated by the script and
includes the `fetched_at` timestamp. Treat any entry older than your refresh interval as stale.

## Limitations

- Listing a model does not guarantee quota, rate limits, or availability.
- This project does not test model quality. It only lists what providers report.
- Provider catalogs change without notice; a parse failure is reported per provider.
